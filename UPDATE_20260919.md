## Installation

Copier les fichiers de chaque archive par-dessus son dépôt existant : koa-linux
et LevelUpDiag-Koali. Ne pas supprimer le dépôt ou les fichiers absents du snapshot.
Conserver les réglages locaux et les ressources non exportées, notamment les SVG.
Fermer puis rouvrir la console LevelUpDiag après copie. Dans le Control Panel,
relancer la préparation du développement pour réimporter le checkout kOA modifié
vers Ubuntu-24.04, /home/rejean/work/koa-linux.

Dans LevelUpDiag : KOALI SYSTEM puis LANCER SÉLECTION pour Windows natif ;
AUDIT SANS VM puis LANCER SÉLECTION pour les sources Linux ; AUDIT TOTAL pour
collecter aussi la documentation et les blocages VM. AUDIT QEMU cible les essais
VM après les niveaux prérequis. STORE reste la campagne indépendante du Store.
La ligne Backend doit afficher Ubuntu-24.04 et /home/rejean/work/koa-linux pour
les audits Linux. Adapter desktop_console.wsl_distro et wsl_target_root dans
levelupdiag.config.local.json si nécessaire. Un ancien override commands.offline
ou commands.system égal à [] désactive encore ces essais : retirer cet override
pour utiliser les commandes du fichier de base.
